炉边（visionOS）与炉边·随身（iOS）是虚拟角色聊天应用。我们尊重你对对话内容与个人资料的控制。

### 我们处理什么信息

- 你输入的称呼、个人介绍、头像选择、聊天消息，以及应用根据对话整理的偏好、事件和角色关系记忆。
- 你自行填写的 AI 服务商 API Key；仅用于向所选服务商发起请求，保存在系统钥匙串中。
- 炉边在你使用语音输入时访问麦克风，并使用系统语音识别将语音转成文字；语音识别的处理方式可能受 Apple 的系统服务与设备设置影响。炉边·随身当前只提供文字聊天。
- 炉边在你启用 Fish Audio 云端音色时，将待朗读文字发送给 Fish Audio 生成语音；不启用时可使用系统语音。
- 炉边可能请求手部追踪和环境感知权限，以实现空间角色的互动与呈现。

### 信息存储与传输

聊天与记忆优先写入用户自己的 iCloud Documents 容器；当 iCloud 不可用时，保存在当前设备。是否跨设备同步取决于 Apple ID、系统及应用的 iCloud 可用状态。你在应用内删除的本地数据与 iCloud 中已同步副本的清除范围需以正式版实际行为为准。

完整 AI 对话以及相关记忆整理会把必要的聊天文本、角色设定和上下文发送给你选择并自行配置密钥的 Claude、OpenAI 或 DeepSeek。服务商对请求的处理、保存期限和跨境传输，受其各自政策约束。请勿在对话中输入你不希望交给相应服务商处理的敏感信息。

我们没有发现当前工程集成广告或分析 SDK；正式提交前仍需核对最终构建及所有依赖。若未来引入开发者服务器、统计 SDK、内置 API Key 或新的数据用途，将先更新本政策与 App Store 隐私披露。

### 你的选择

你可在应用内切换 AI 服务商、编辑个人资料。炉边·随身提供记忆检查器，可逐条管理记忆并清空角色对话；炉边目前没有相同的逐条记忆管理界面。你也可以在系统设置中管理权限和 iCloud。API Key 可在应用中更换；当前界面未见删除入口，需在发布前提供明确的删除方式并据此修订本段。

### 儿童与安全

本应用不作为医疗或心理危机处置工具。年龄分级及未成年人使用方式将按 App Store Connect 问卷和正式产品行为确定。

## 支持页草稿

标题：炉边 / 炉边·随身 — 帮助与支持

炉边是 Apple Vision Pro 上的空间角色聊天应用；炉边·随身是 iPhone 上的文字聊天应用。要使用完整 AI 对话，请在应用的 API Key 设置中选择 Claude、OpenAI 或 DeepSeek，填写你自己的有效密钥。Key 不由应用提供；第三方服务可能产生费用。

常见问题：

1. **没有 API Key 能使用吗？** 可以浏览角色并体验有限的预设回应；完整 AI 对话需要有效 Key 和网络。
2. **对话放在哪里？** iCloud 可用时优先同步至你的 iCloud；否则仅保存在当前设备。请在应用设置中查看当前存储后端。
3. **为什么语音不可用？** 语音功能仅在炉边提供。请检查麦克风、语音识别权限；Fish Audio 云端音色另需自备其 API Key。
4. **怎样管理记忆？** 炉边·随身有记忆检查器，可查看、编辑或删除记忆，并清空角色对话。炉边当前没有相同的逐条管理界面。

## 发布前必须处理

1. 隐私政策和支持页已发布到无需登录即可打开的 HTTPS 地址；仍需分别填写到两款 App 的 App Store Connect，并在 App 内加入容易找到的隐私政策入口。Apple 要求在元数据和 App 内提供隐私政策链接：[App Review Guidelines 5.1.1](https://developer.apple.com/app-store/review/guidelines/)。
2. 逐项核对第三方 AI 与 Fish Audio 的数据处理、保留及披露，并完成 App Privacy 问卷。Apple 明确要求涵盖第三方合作方的数据收集：[Manage App Privacy](https://developer.apple.com/help/app-store-connect/manage-app-information/manage-app-privacy/)。
3. 核实 API Key 是否可在 App 内删除，以及 iCloud 数据删除的实际效果，修订上文相关段落后再公开。不要带方括号占位符提交。
