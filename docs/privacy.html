隐私政策

适用于「炉边」（visionOS）和「炉边·随身」（iOS） · 生效日期：2026 年 11 月 7 日

聊天内容与记忆优先保存在你自己的 iCloud，无法使用 iCloud 时保存在设备上；个人资料保存在当前设备。完整 AI 对话会将相关文本发送给你选择的服务商；Vision Pro 版启用 Fish Audio 时还会发送待播报文字。

我们处理的信息

应用会处理你输入的称呼、个人介绍、聊天消息和头像选择，以及根据对话生成的偏好、事件与角色关系记忆。完整 AI 对话需要你自行填写所选服务商的 API Key。密钥保存在系统钥匙串中，用于从设备向服务商发起请求。

目前的应用没有账号系统，也未集成广告或分析 SDK；开发者不运营用于接收这些聊天数据的服务器。应用功能仍会按下文所述使用 Apple 服务和你选择的第三方服务。

AI 对话与第三方服务

选择 Claude、OpenAI 或 DeepSeek 并配置密钥后，应用会把生成回复所需的聊天文本、角色设定和相关上下文发送给该服务商。应用也可能使用对话内容更新角色记忆，这同样需要调用所选服务商。没有有效密钥时，只提供有限的预设回应。

服务商对请求的保存、使用和跨境处理由其各自的隐私政策及你的账户设置决定。请不要输入你不愿交给所选服务商处理的敏感信息。

语音和空间权限

仅 Vision Pro 版「炉边」提供语音输入。你使用语音输入时，应用请求麦克风与 Apple 语音识别权限，将语音转为文字。语音识别是否在设备上完成取决于 Apple 的系统能力与设置；我们不把语音识别描述为始终离线。

炉边可用系统声音朗读回复。若你配置并启用 Fish Audio 云端音色，待朗读的文本会发送给 Fish Audio，换取语音音频。炉边还可能请求手部追踪与环境感知权限，用于空间中的角色呈现与互动。iPhone 版「炉边·随身」目前仅提供文字聊天。

存储、同步和保留

聊天记录与角色记忆优先写入你自己的 iCloud Documents 容器，在 iCloud 不可用时保存在当前设备。个人资料（称呼、介绍和头像选择）保存在当前设备的应用设置中。是否同步取决于 Apple ID、系统及应用的 iCloud 配置。开发者无法访问你的 iCloud 私有容器。

这些内容会保留在相应存储位置，直到你通过应用提供的功能删除，或自行管理设备和 iCloud 中的应用数据。炉边·随身提供记忆检查器，可查看、编辑和删除记忆，并可清空角色对话；炉边当前没有相同的逐条记忆管理界面。发送给第三方服务商的数据保留期限由该服务商决定。

你的选择与联系

你可以更换 AI 服务商和 API Key，并在系统设置中管理麦克风、语音识别、手部追踪等权限。当前版本没有单独的 API Key 删除按钮；如需获得操作帮助，请通过下方邮箱联系。我们无法直接从你的设备或第三方服务商账户中替你删除数据。
