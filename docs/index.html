两款应用

炉边适用于 Apple Vision Pro：原创 3D 角色出现在空间中，支持文字和语音交流。

炉边·随身适用于 iPhone：与不同性格的原创角色进行文字聊天，并查看、管理对话记忆。

常见问题

为什么角色只能简单回应？

没有配置 API Key 时，应用只提供有限的预设回应。要使用完整 AI 对话，请打开应用中的「API Key 设置」，选择 Claude、OpenAI 或 DeepSeek，填写你自行申请的有效密钥。第三方服务商可能收取费用。

聊天记录保存在哪里？

应用优先使用你自己的 iCloud Documents；iCloud 不可用时改为保存在当前设备。「炉边·随身」设置页会显示当前存储后端。跨设备同步取决于 Apple ID 与 iCloud 的可用状态。

为什么语音输入或播报不能使用？

语音功能仅在 Vision Pro 版「炉边」提供。请检查麦克风与语音识别权限。系统语音播报不需要 Fish Audio 密钥；Fish Audio 云端音色需要另行配置其 API Key。

怎样管理聊天记忆？

在「炉边·随身」的设置中打开记忆检查器，可查看、编辑或删除记忆，也可以清空当前角色对话。Vision Pro 版目前没有同样的逐条记忆管理界面。
